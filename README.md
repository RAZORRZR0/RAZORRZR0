## Hi, I'm RAZORRZR

CS graduate working on **reverse engineering and game modding**. I mostly write x64 ASI plugins for *GTA San Andreas: The Definitive Edition*, port them to the game's Android release, and build tools for *Tekken*: find the engine code by byte signature, hook it, and fix or extend what the shipped game does.

### GTA San Andreas: The Definitive Edition (PC)

| Project | What it does | Release |
|---|---|---|
| [SkyGfxDE](https://github.com/RAZORRZR0/SkyGfxDE) | Brings back the PS2 look on DE's UE4 renderer: PS2 colour filter and timecyc, radiosity, SpeedFX, classic fog. Adds an in-game debug menu | ![](https://img.shields.io/github/v/release/RAZORRZR0/SkyGfxDE?style=flat-square&label=) |
| [GTA_Prop_Fix](https://github.com/RAZORRZR0/GTA_Prop_Fix) | Knocked-over street props use the original RenderWare physics instead of falling through the world | ![](https://img.shields.io/github/v/release/RAZORRZR0/GTA_Prop_Fix?style=flat-square&label=) |
| [DX12AMDFix](https://github.com/RAZORRZR0/DX12AMDFix) | Fixes the `-dx12` City Glow crash (unsupported 4x4 VRS), the idle stutter and the stuck engine-sound loop | ![](https://img.shields.io/github/v/release/RAZORRZR0/DX12AMDFix?style=flat-square&label=) |
| [DE_LimitAdjuster](https://github.com/RAZORRZR0/DE_LimitAdjuster) | x64 port of Open Limit Adjuster, with a monitor that logs how much of each pool the game uses | ![](https://img.shields.io/github/v/release/RAZORRZR0/DE_LimitAdjuster?style=flat-square&label=) |
| [ProjectPropsDE](https://github.com/RAZORRZR0/ProjectPropsDE) | Port of Project Props 4 (16k props), plus IplActorsDE, which renders new IPL placements | ![](https://img.shields.io/github/v/release/RAZORRZR0/ProjectPropsDE?style=flat-square&label=) |
